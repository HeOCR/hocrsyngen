# Photocopy confirmation gallery

Ten clean and photocopy pairs use the approved LookScanned-based
`bw_photocopy` profile. The 55/35/10 TRAIN mix rounds to six light,
three medium and one harsh example here. Every photocopy is a one-bit PNG.

All controls re-render the screened [Realism v2 copy](../realism_v2_preview/copy.json)
with its original lines. The same accepted label appears on both sides. Gallery
selection requires retained ink on every annotated line. The [manifest](generation_manifest.json)
records the seed, working PPI, exact label hashes and image hashes for each pair.
The new gallery is [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
It uses generated pages only.
