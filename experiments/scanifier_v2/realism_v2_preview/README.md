# Realism v2 · Hebrew scan preview

Twenty paired synthetic pages. The left and right pages use the same Hebrew
copy. The left uses a uniform print layout. The right varies type and capture
together so you can see the combined effect. Select either image to open the
full 960 × 1240 preview.

| Pairs | Capture treatment |
| --- | --- |
| [01–05](#duplex-transmission) | Warm stock, mirrored back-page ink and uneven transmission |
| [06–10](#platen-and-photocopy) | Screened grayscale, patchy noise and black platen bands or streaks |
| [11–15](#bound-book) | Green-toned paper, soft gutter shadow, dark binding fringe and faint show-through |
| [16–20](#handheld-phone) | Angled page, desk shadow, uneven illumination and JPEG contrast |

## Source and reuse

All 40 JPEGs and the original Hebrew text in [copy.json](copy.json) are
dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The front and reverse pages are drawn from that text. No source capture
pixels, real document excerpts, or encoder tables enter the pack. The existing
[bundled fonts](../../../src/hocrsyngen/data/synthetic/fonts) retain their
individual SIL Open Font Licenses. The manifest records each font and its
digest.

The base optics and tone use the [public Scanifier presets](../presets/README.md)
derived from non-test development captures. Typography, stronger texture,
duplex, scanner margins and the phone framing are explicit preview settings.
The bolder doses illustrate appearance under stress and are outside the base
fit. This pack is for visual review.

## Reproduce

From the repository root, use Python 3.12 and install Scanifier's experiment
requirements with Pillow and libraqm. The checked pack was generated with
Pillow 11.3.0, NumPy 2.3.1 and OpenCV 4.13.0.

```sh
PYTHONPATH=. python experiments/scanifier_v2/realism_v2_preview/build_preview.py \
  --output /path/to/new/replay/images
```

[The generation manifest](generation_manifest.json) binds each seed, preset,
JPEG digest, and the literal line text, typography and bounds for both sides.
Phone line bounds also include the projected corners. Reverse text is stored
in the copy file so the ghost ink can be reproduced. It is separate from the
front labels.
