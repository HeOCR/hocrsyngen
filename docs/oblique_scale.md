# Oblique SDXL TRAIN candidates

The experimental worker in experiments/scanifier_v2/oblique_scale.py takes a
hash-pinned native TRAIN roster with lines in exact producer order. It
renders new Blender plates from seeded authored phone poses. The stock
capture renderer receives no fitted optics or photometry. A fresh SDXL
pass on each blanked synthetic camera plate proposes low-frequency
illumination. Sampling excludes every line polygon, and an inked paper
model receives the resulting field without copying generative pixels.
Some views add texture, narrow hard cast shadows or rounded creases.

The worker tests camera fiducials and crease round trips, ring halo
levels and paired Tesseract reads. It preserves source line text through
each projection. Its manifest pins the model, media, geometry and
per-view inherited assets. Candidate data receives independent TRAIN
CLEAN before model intake. Nested dose selection happens on the signed
membership outside this repository.

Run the module with --help for the required inputs. The optional RunPod
wrapper requires the pinned source tar, roster and native rasters,
CC0 Blender scene assets, the public pretrained SDXL component manifest,
and the exact traineddata used for the paired reader. No optional GPU
packages are added to the hocrsyngen installation.
